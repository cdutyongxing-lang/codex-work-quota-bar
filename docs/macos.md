# macOS 使用说明

## 安装

1. 从本仓库 Releases 下载 `CodexWorkQuotaBar-macOS.zip`。
2. 解压，将 `CodexQuotaBar.app` 移入“应用程序”。更新时先从菜单退出旧版，再替换应用。
3. 双击打开，查看屏幕顶部菜单栏。它没有普通主窗口和 Dock 图标。
4. 打开已登录的 ChatGPT / Codex 主应用，等待首次读取。

菜单栏中的 `5h 80% · 周 65%` 表示剩余额度。这里只是示例，实际以账户返回为准；部分账户可能只返回一个窗口或没有额度数据。

应用使用 ad-hoc 本地签名，尚未经 Apple Developer ID 签名 / 公证。若系统拦截，请先确认下载来源，再参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)决定是否允许打开，不必关闭整个系统的安全保护。

## 额度与刷新

约每 60 秒读取一次。点击“立即刷新一次”可提前触发一次读取；即使已暂停自动刷新，也可以手动读取一次，完成后仍保持暂停。已有请求正在进行时不会重复发送。正常任务执行会改变额度，查询本身没有模型任务。

点击菜单查看两个窗口的重置倒计时。悬停在额度条上可查看重置日期及最后读取时间；重置日期采用北京时间。到点后等待接口确认，不会自行把额度改为 100%。

主应用位于后台时仍会查询。选择“暂停自动刷新”停止后续定时刷新并隐藏悬浮条，菜单栏标记“已暂停”；已发出的请求可能完成。选择“恢复自动刷新”会立即尝试读取。

主应用退出后，旧数据会标记“待更新”；重新打开后会重新连接。如果你主动暂停过自动刷新，主应用重新打开后仍保持暂停，可手动刷新一次或选择恢复。暂停不写入用户偏好，完全退出并重开额度条后默认开启自动刷新。

选择“退出额度条”结束程序。

## CLI 登录

工具优先查找主应用内的 CLI，再查找 `/opt/homebrew/bin/codex`、`/usr/local/bin/codex` 和 PATH。已手动指定的路径优先级最高。

如果提示找不到 CLI，可在菜单中选择“选择 Codex CLI…”。新版应用的常见内置相对路径为：

```text
Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex
```

CLI 必须登录与桌面应用相同的 ChatGPT 账户。对已安装并加入 PATH 的官方 CLI，可在终端运行：

```bash
codex login status
codex login
```

如使用应用内置 CLI，请对所选可执行文件运行相同子命令。无需将密码、API Key 或登录文件交给本工具或仓库维护者。API Key 模式未必提供订阅额度信息。

## 可选：跟随输入框

1. 菜单栏中勾选“跟随 ChatGPT 窗口（需辅助功能）”。
2. 在系统设置中自行决定是否授予该工具辅助功能权限。
3. 切回主应用。如未出现，可退出并重开工具。
4. 若自动定位失败，选择“手动校准位置”，按提示切回主应用，拖到输入框附近的空白处，再右键选择“完成校准”。

空间不足时悬浮条可能简化显示或隐藏。菜单栏仍可查看额度。自动定位受主应用版本与窗口布局影响；多屏和登录启动尚需更多实机验证。取消跟随开关会停止后续窗口定位；也可在系统设置中撤销辅助功能权限。

## 登录启动与移除

先把应用放到稳定位置，再勾选“随 macOS 登录启动”。系统可能要求批准登录项。此功能默认未开启。

移除前取消登录启动并退出工具，再将应用移入废纸篓。无需删除 Codex 的登录文件。工具的用户偏好保存在 `io.github.codexquotabar.work.local` 域中。

## 常见问题

**双击后没有窗口？** 正常，它是菜单栏应用。查看顶部的圆环与百分比；若图标被其他菜单栏项目挤出，可减少其他项目后确认。

**只有圆环，没有数字？** 点击菜单查看状态；确认主应用已经打开、CLI 已登录且网络可用，稍等或选择“立即刷新一次”。

**重新打开主应用后不刷新？** 先查看菜单栏是否标记“已暂停”。若已暂停，可点击“恢复自动刷新”，或“立即刷新一次”进行单次读取。v1.0.2 修复了旧版暂停时“立即刷新”没有生效的问题，更新前请先退出旧版额度条。

**显示“待更新”？** 当前读取失败，仍显示上次成功的数据；查看提示中的读取时间，不要把它当作最新值。

**两个账户额度不一致？** 工具显示的是所选 CLI 的账户额度；检查 CLI 与桌面应用是否使用同一账户。

**只有一个额度窗口？** 工具只显示服务端返回的数据，不补造另一个窗口。
